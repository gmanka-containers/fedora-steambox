### features

- based on fedora
- can work as nested gamescope window
- can work as standalone gaming mode gamescope session in your login manager
- switch to desktop button closes steam and throws you to your login manager
- can run your host apps and desktops from gamescope session
- proton ge preinstalled and listed in steam compatibility tools list
- mangohud preinstalled
- toolbox supports proprietary nvidia drivers integration out of the box
